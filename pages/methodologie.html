Données retenues

L'application retient trois familles de données : le transport domicile - université, les repas pris sur une semaine et les usages numériques liés aux études.

Catégorie Données demandées Source principale
Transport mode de transport, distance, jours de présence, aller-retour Impact CO2
Repas nombre de repas végétaliens, végétariens, poulet, poisson, boeuf Impact CO2 / AGRIBALYSE
Numérique heures de streaming, heures de visioconférence, emails envoyés Impact CO2

Choix de conception

L'application est réalisée individuellement en HTML, CSS et JavaScript, afin de rester cohérente avec les apprentissages du cours et avec les défis précédents.

Facteurs utilises dans l'application

Transport

  • Métro : 4,44 g CO2e / km
  • Bus thermique : 122 g CO2e / km
  • TGV : 2,93 g CO2e / km
  • Voiture électrique : 103 g CO2e / km
  • Voiture thermique : 218 g CO2e / km
  • Covoiturage : 109 g CO2e / km

Repas

  • Repas végétal / végétalien : 0,39 kg CO2e
  • Repas végétarien : 0,51 kg CO2e
  • Repas avec poulet : 1,58 kg CO2e
  • Repas avec poisson : 1,98 kg CO2e
  • Repas avec boeuf : 7,26 kg CO2e

Numérique

  • Streaming : 31,6 g CO2e / heure
  • Visioconférence : 16 g CO2e / heure
  • Email : 0,104 g CO2e / email

Les facteurs numériques ont été simplifiés à partir des équivalences publiques affichées sur l'outil Usage numérique d'Impact CO2 afin de disposer d'un calcul hebdomadaire clair et directement exploitable dans une application web.

Formules de calcul

  • Transport = facteur transport x distance x nombre de trajets hebdomadaires
  • Repas = somme des repas x facteur de chaque type de repas
  • Numérique = streaming + visioconférence + emails
  • Total hebdomadaire = transport + repas + numérique
