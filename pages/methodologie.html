Transparence

Méthodologie et facteurs d’émission

Les calculs reposent sur des facteurs publics simplifiés pour une lecture hebdomadaire.

Périmètre

Données retenues

L’application retient trois familles de données : le transport domicile-université, les repas pris sur une semaine et les usages numériques liés aux études.

Ce projet est un projet universitaire personnel. Il n’est affilié à aucun service officiel de calcul carbone.

Catégorie Données demandées Source principale
Transport mode de transport, distance, jours de présence, aller-retour Impact CO2
Repas nombre de repas végétaliens, végétariens, poulet, poisson, boeuf Impact CO2 / AGRIBALYSE
Numérique heures de streaming, heures de visioconférence, emails envoyés Impact CO2

Conception

Choix techniques

L’application est réalisée en HTML, CSS et JavaScript natif. Les résultats sont stockés avec localStorage pour conserver une expérience simple, compatible avec GitHub Pages et sans dépendance externe.

Facteurs

Valeurs utilisées dans l’application

Transport

  • Métro : 4,44 g CO₂e / km
  • Bus thermique : 122 g CO₂e / km
  • TGV : 2,93 g CO₂e / km
  • Voiture électrique : 103 g CO₂e / km
  • Voiture thermique : 218 g CO₂e / km
  • Covoiturage : 109 g CO₂e / km

Repas

  • Repas végétal / végétalien : 0,39 kg CO₂e
  • Repas végétarien : 0,51 kg CO₂e
  • Repas avec poulet : 1,58 kg CO₂e
  • Repas avec poisson : 1,98 kg CO₂e
  • Repas avec boeuf : 7,26 kg CO₂e

Numérique

  • Streaming : 31,6 g CO₂e / heure
  • Visioconférence : 16 g CO₂e / heure
  • Email : 0,104 g CO₂e / email

Les facteurs numériques ont été simplifiés à partir des équivalences publiques affichées sur l’outil Usage numérique d’Impact CO2 afin de disposer d’un calcul clair et directement exploitable dans une application web.

Formules de calcul

  • Transport = facteur transport x distance x nombre de trajets hebdomadaires
  • Repas = somme des repas x facteur de chaque type de repas
  • Numérique = streaming + visioconférence + emails
  • Total hebdomadaire = transport + repas + numérique
